# Data

Version controlled data which can be accessed via URLs.

## File Descriptions

- **napistu_nets_configs.zip** - yaml configs and shell script for training and publishing the models used in [Napistu meets PyTorch Geometric - Predicting Regulatory Interactions with Graph Neural Networks](https://www.shackett.org/napistu_torch/).
- **napistu_nets_models.zip** - model outputs including checkpoint for the models trained using `napistu_nets_configs.zip`.
- **octopus_input_sbml_dfs_summaries.json** - `SBML_dfs.get_sbml_dfs_summary` summaries from the 8 sources described in [Napistu's Octopus: An 8-source human consensus pathway model](https://www.shackett.org/octopus_network/).
